# Outrix Data Analyst Projects

This repository contains three data analytics projects completed as part of the **OUTRIX Data Analyst Traineeship** (1-month, project-based, remote). Each project covers the full analytics workflow — data cleaning, transformation, SQL querying, and dashboard development — using **Python (Pandas), Excel, SQL, and Power BI**.

---

## 📊 Project 1: Online Delivery Analysis (Zomato Dataset)

**Files:** `zomato_Dataset.csv`, `ZomatoOnlineAnalysis.pbix`

- Cleaned and transformed **9,500+ restaurant records** using Python Pandas, removing duplicate and incomplete entries to build an analysis-ready dataset.
- Built an interactive **Power BI dashboard** with DAX measures, calculated columns, KPIs, donut charts, maps, and slicers.
- Evaluated online delivery trends, restaurant ratings, and distribution across countries and cities to generate actionable insights.

**Tools:** Python (Pandas), Power BI, DAX

---

## 👥 Project 2: HR Analytics Dashboard

**Files:** `HR_Analytics.csv`, `HR_DASHBOARD.pdf`

- Built a comprehensive HR analytics dashboard covering **1,480+ employee records** to monitor performance, attrition, and headcount.
- Presented HR KPIs including attendance trends, hiring metrics, and department-wise analysis using Power BI.
- Analyzed attrition by age group, salary slab, education, job role, and years at company using interactive visuals.

**Tools:** Power BI

---

## 📱 Project 3: Mobile Sales Dashboard

**Files:** `Mobile Sales Data.xlsx`, `MobilesSalesDashboard.pbix`

- Cleaned and transformed **3,800+ sales transactions** using Microsoft Excel and Python Pandas to prepare a reliable dataset for analysis.
- Used SQL for data querying and aggregation, then developed an interactive **Power BI dashboard** with KPIs, maps, slicers, donut charts, and clustered column charts.
- Added KPIs for Total Sales, Quantity, and Average Order Value, with Male/Female slicers to compare sales performance and identify trends.

**Tools:** Microsoft Excel, Python (Pandas), SQL, Power BI
